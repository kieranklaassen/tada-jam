The adopted health education standards as a PDF. It is the canonical rendition for the eight overarching standards in cross-grade practical life and feelings (Appendix, PDF page 66; printed again with rationales on PDF pages 7 and 8) and the check rendition for the health export.

Standing: the publishing page says the State Board adopted the standards on March 12, 2008. The document carries the notice that it is not binding on local educational agencies.

Read with pdftotext in plain mode; layout mode also yields every grade code.

Artefacts: the PDF prints a code without its grade, under a page header that names the grade, so the same printed code recurs in several grades. Plain mode drops line-break hyphens ("healthrelated"). The text layer holds 3 soft hyphens and 68 control characters. The introduction is two columns, and plain mode returns the overarching standards there out of order.
