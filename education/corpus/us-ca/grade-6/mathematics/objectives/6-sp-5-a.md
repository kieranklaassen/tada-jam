## Summary

_The pack's summary, not the official text._

The child sums up a numerical data set with its context in view. One way of doing so, the one named in this part, is saying how many observations there are.

## Design notes

_The pack's inference, not the official text._

### In a child's hands

The child counts the dots on a dot plot or the entries in a list and writes "24 students were measured". The child checks the count against the number of people or things that were to be measured and notes whether any are missing. The child says what one observation is: one student, one plant, one day.

### Limits

The stem introduces its parts with "such as", so the four parts (a to d) are examples of what a summary holds, not a closed list. This part asks only for the count of observations. The statement sets no size for the data set. The cluster heading names the purpose of this group: describing distributions and giving summaries of them.

### Common mistakes

Counting how many different values there are instead of how many observations, so that repeated values are counted once. In a histogram, counting the bars instead of adding the bar heights. Giving the sum of the data values when the count is asked.
