## Summary

_The pack's summary, not the official text._

While solving a problem, from real life or from mathematics itself, the child lets a variable stand for a number and writes expressions with it. The child understands two uses of a variable: it may be one number that is not yet known, or, according to the purpose, it may be any number from a stated set.

## Design notes

_The pack's inference, not the official text._

### In a child's hands

The child reads "a girl has some stickers and gets 5 more", chooses a letter for the number of stickers, says aloud what the letter counts, and writes s + 5. The child fills a table for s + 5 with several values of s and so treats the letter as any number of stickers. In a problem with one answer, the child treats the letter as the single number to be found.

### Limits

A variable has two stated meanings: an unknown number, and any number in a stated set. The statement sets no number range and names no operations. The cluster heading adds that the equations and inequalities of this group have one variable. Two variables that depend on each other are covered by 6.EE.9.

### Common mistakes

Using the letter as an abbreviation for the object ("s means stickers") instead of the number of objects. Believing that a letter always hides one fixed value, or that two different letters must be different numbers. Thinking that a letter's value comes from its place in the alphabet.
