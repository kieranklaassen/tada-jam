## Summary

_The pack's summary, not the official text._

Box plots, histograms and dot plots are among the plots on a number line that the child makes to show numerical data.

## Design notes

_The pack's inference, not the official text._

### In a child's hands

The child draws a number line that covers the data and places one dot above the line for each value to make a dot plot. For a histogram, the child chooses equal intervals, tallies how many values fall in each interval, and draws bars that touch. For a box plot, the child puts the values in order, finds the median and the two quartiles, and draws the box and the two whiskers above the same number line.

### Limits

The data are numerical, and every display sits on a number line. Three kinds of plot are named after the word "including", so the list is not closed. The statement sets no size for the data set and no number range. Displays of data in categories are not mentioned. The cluster heading names the purpose of this group: describing distributions and giving summaries of them, which the parts of 6.SP.5 spell out.

### Common mistakes

Spacing the number line unevenly, or leaving out values that have no data, which distorts the shape. Drawing a histogram with gaps between the bars or with unequal intervals. In a box plot, finding the median without ordering the data first, or thinking that a longer section of the box holds more data values.
