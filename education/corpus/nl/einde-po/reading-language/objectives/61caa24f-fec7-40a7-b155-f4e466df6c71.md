summarising content that has been read;

## Design notes

_The pack's inference, not the official text._

### In a child's hands

A child of 11 or 12 reads a text about the Romans in the Netherlands, underlines the key sentence of each paragraph, and then writes a short text of the child's own that gives the main points in order and leaves the examples out. Someone who has not read the original can tell from the summary what it said.

### Limits

This is an item under goal sentence 3 C, which says that the pupil writes in order to build knowledge or reach understanding; 3 C sits under core goal 3. It names only content that has been read; content that has been watched or listened to, which item 3 C a names, is not named here. It sets no length for the text or for the summary, names no kind of text and sets no level.

### Common mistakes

A child copies sentences from the text and joins them. A child retells the whole text at nearly the length of the original. A child keeps a striking example and leaves out the point that it illustrates.
