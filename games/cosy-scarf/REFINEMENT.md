# Cosy Scarf: thirty refinement passes

Each pass follows the [refinement loop](../../docs/solutions/workflow-issues/refinement-loop-for-kid-3d-readability.md): screenshot or record, write an honest critique, make one focused set of changes, re-screenshot, and re-measure. Passes that fix a place where the game contradicted one of the jam's compound docs say which doc.

**How each pass was measured.** Look passes use a fresh-state production build (`npm run build`, served by `vite preview`), 1180×820, touch, on a fake clock (Playwright `page.clock`, 33 ms steps), with the shot taken 6.5 s after load so the idle glow and the first ghost-hand demonstration are in frame. Motion passes record the same build as frame sequences. Every pass then re-runs the shared jam probe (`perf-probe.mjs`) on the production build: Chromium, 6× CPU throttle (CDP), 1180×820, DPR 2, touch, 4 s warm-up, 10 s of sampling with 12 scattered taps (30 s from pass 3 on: at 2.6 fps, 10 s is only 26 frames, too few for a steady p95). It reports `cpuP95Ms` (the game's own update plus render submit per frame, from `window.__jamPerf`) and the renderer's draw calls. The cloud VM has no GPU (Chromium renders with SwiftShader at about 2.6 fps at DPR 2), so frame rate here says nothing about an iPad; CPU per frame and draw calls are the proxies, and WebKit fps is compared against Pebble Table in the same session at the end. No physical iPad was measured.

| 1: stage | A thin white line ran along the back of the play blanket: the raised rib border floated above the inner blanket, and the snow showed through the gap. The loom's large dark backboard read as an empty doorway, and the two crossed needles under the rod read as a wooden brace, so nothing said "knitting happens here". | The blanket base now runs under the border. The backboard is a hanging felt cloth: a shade lighter where it hangs, a quiet running stitch round its edge, two felt loops over the rod. The needles lie almost parallel and carry a row of live loops, cream cast-on loops on an empty loom and the last row's colours once knitting starts (one instanced mesh, recoloured only when a row lands). | 7.9 ms / 21 |
| 2: the want | Contradicted [wordless clarity](../../docs/solutions/conventions/wordless-clarity-for-the-declared-age-band.md) ("one obvious want"). In the cold playtest proxy the bunny stood with its arms open and its ears up in a V: it read as "hello", not "I'm cold", and nothing it did changed as the scarf grew. The cause was a flipped sign: the cold "hug" swung both arms outward. The same proxy run found that no tap ever knitted: the VM's audio runs at 44.1 kHz, the room reverb was built at 48 kHz, and the convolver threw inside the first touch handler, so every touch was dropped (on an iPad with Bluetooth headphones too). Pass 1's number was therefore measured with taps that did nothing. | Cold arms now wrap the belly (bunny and bear), the bunny's ears flop out sideways, every cold animal wears a lump of snow on its head that lifts off in a white puff as the scarf warms it, and each breathes frosty puffs at its own pace (bunny 1.7 s, fox 2.2 s, penguin 2.7 s, bear 3.4 s). Each row knitted for the waiting animal eases its shiver and blue tint and pinks its cheeks, so every row visibly helps. Sound builds its samples at the device's own rate, and a sound that cannot start can no longer stop a touch (tested with a fake 44.1 kHz context and a broken one). | 8.2 ms / 23 |
| 3: personality | Contradicted [motion personality per character](../../docs/solutions/design-patterns/motion-personality-per-character.md). Each animal had one fixed idle and one fixed tap reaction that replayed identically. A tap on a warm animal restarted a shortened copy of its dance, so its "own happy dance" stopped being special. The eyes never closed, and when a pattern repeated the code set an "answer" time that nothing ever read. | A pure `motion.ts` holds one personality per species: its own breathing tempo, look speed, blink, and reaction lag, plus two to four variants for each moment (poke while cold, pet while warm, a row finished, a pattern answered, the cold ask, idle delights). A seeded director never plays the same variant twice in a row, varies each playback's size and speed, and stays still while the animal walks, dances or the child is knitting. While cold, the animal asks every few seconds by looking at the loom and pointing to the basket. Every row finished for the waiting animal gets its own small reaction. Warm animals answer a repeated pattern at their own lag and now blink. Dances play only for the gift. Tests enforce variants, no near-copies across species, the tempo order, never-repeat, and staggered reactions. | 9.6 ms / 24 |
| 4: frame budget | Contradicted [measure on the target device](../../docs/solutions/performance-issues/measure-on-the-target-device-and-ship-adaptive-quality.md) (no per-frame allocation, no GC spikes), and pass 3 was over the 8 ms target at 6×. Idle frames spiked to 18–33 ms. A sampling heap profile of an unminified build showed three.js rebuilding program parameters every frame: the pines drew the crochet material instanced while the loom and butterfly drew it plain, so the renderer re-picked the program at every switch. Logging every program link showed that dropping to the lowest tier compiled the flat-hillside shader mid-play, on the very frame the device was already struggling. | The pines get their own copy of the crochet material. The load-time prewarm compiles every tier's material state, not only the two post-pass variants, so a tier change never compiles. The pose reset copies a rest pose instead of looping over channel names. After warm-up the page allocates 9.5 KB a frame (three.js 5.4, the native sort 1, the game 2.4), all of it V8 boxing numbers that cross function calls; the game makes no objects, arrays or closures per frame, and Safari's engine does not box numbers. 30 s of idle at 6× now has no minor collections (Pebble Table: 4); the only pauses left are V8's major collections just after load, which stop once the heap settles at 7.5 MB. Under 4× throttle the game falls to tier 3 with no program linked after load. | 6.5 ms / 24 |
