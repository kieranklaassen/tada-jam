# Every Demo a Jam Game - Plan

## Goal Capsule

- **Objective:** Every lab demo the owner did not rate "No" is a real jam game: a cartridge under `games/`, at the quality bar, with its own look, worth coming back to for weeks at the child's age.
- **Product authority:** The owner's answer "Every demo" of 2026-10-10 to "Turn which demos into real jam games in this run?", then `AGENTS.md`, the guide `docs/solutions/conventions/building-a-jam-game.md` and the game-design pack. This is the wave that R15 of `docs/plans/2026-10-10-2327-feat-one-jam-of-playable-games-plan.md` says is planned separately.
- **Means:** One builder per game, each in its own worktree cut from one base commit; the lead owns every shared file and makes every commit (W9).
- **Stop conditions:** A game below the bar at the end is not merged and is listed (W12). The run stops if a change would need a file under `education/` or the wording store.
- **Who finishes:** The lead opens the pull request. The owner plays, answers on the looks and the toys, merges and deploys.
- **Open blockers:** None. The count differs from the brief: the files give 35 demos with no game, not 36 (see Dependencies).

## Product Contract

### Summary

The 56 demos under `lab/arcade/protos/` less the 16 that already have a game and the five rated "No" leave 35. Each is rebuilt as a jam game from the template, taking the demo's idea, verb and feel in the hand and none of its code. The 23 calm, building and open-play demos mostly keep their verb and gain characters with fixed tastes and a grid of combinations. The 12 one-verb and arcade demos lose their scores, coins, shops, upgrades, rare drops, timers and rising speed; each keeps its fantasy and its feel and gets a reshaped loop that a child paces.

### Key Decisions

- **No learning goal.** No demo's verb is plainly a school skill, so no sheet has a records part and no game claims a school skill (guide, "The design sheet": "A game with no learning goal has no records part"). Governs W3.
- **A demo that leans on reward, reflex or luck gets a new verb or a reshaped loop**, keeping its fantasy and its feel in the hand (guide, step 1 and the defaults awaiting the owner; pack: game-design, no-rewards-for-playing.md; pack: game-design, the-line-between-depth-and-manipulation.md; pack: game-design, hidden-never-counted.md). Governs W4, W5.
- **Lively and funny, the calm ones too.** The owner rated the lively job demos "Build it"; every game here has someone large in the frame who reacts, and a wrong use that works and is the better joke (pack: game-design, liveliness-from-causing-and-comedy.md; pack: game-design, characters-with-opinions.md; pack: game-design, a-full-frame-with-large-funny-characters.md). Governs W6.
- **The toy checkpoint is not held in this run.** The owner asked for everything at once, so every look and every toy is a default awaiting the owner's yes, listed in the pull request. Governs W11.
- **One look per game, none shared.** Each game has a first and a second look reserved in the ledger of `docs/art-direction.md`. Seven looks that `lab/arcade/GENTLE.md` assigned are already claimed by other games or sit too close to one (felt-tip marker, linocut, chalk on asphalt, wet watercolour, sand tray, rainbow wood, cut-paper diorama); those games get the nearest look that a screenshot could not confuse with the claimed one. Governs W7.
- **Chalk Town becomes Tape Town.** A chalk drawing that vehicles follow is Chalk Train's look and verb, so the game lays tape roads on a floor and takes the key `tape-town`; the lab catalog needs `game: 'tape-town'` on `chalk-town` so the home page lists it once. Governs W2.

### Requirements

- W1. Each of the 35 demos in the table below is a game in `games/<key>/`, started from the template with the key, name, band and emoji given there, and it passes the jam's checks on the merged tree.
- W2. A game keeps its demo's key, so the home page shows it once. The one exception is `tape-town`, which the lab catalog names on `chalk-town`.
- W3. Each game's `ART.md` holds a design sheet under the guide's headings, without a records part, written before any game code and checked by someone who did not write it.
- W4. No game shows a score, coin, shop, upgrade, level number, streak, timer, tally of finds or praise, and none has an outcome a child wants that comes by luck or by amount of play.
- W5. No game moves by a clock the child did not start: nothing speeds up, nothing is lost by waiting, a failure is funny and costs nothing, and the next cycle waits for a touch.
- W6. Each sheet holds an object-by-action grid in which every cell looks and sounds different, a wrong use that works, and the day-15 line given below or a better one.
- W7. Each game is built in its first reserved look and moves to its second only if the spike fails on clarity or frame rate or the owner rejects the look. No two games share a look.
- W8. Each game is found as left when put away at any instant, pauses when unattended, and is wordless for its band; no game in this wave draws a numeral, though eight bands start at 6 or above.
- W9. A builder changes only `games/<key>/` and, for a three.js game, `scripts/intersections/games/<key>.ts`, and runs no git command that writes. The lead commits at each stage boundary and owns the ledger, the registry, the README and the lab catalog.
- W10. A canvas game ships its own model overlap tests; a three.js game takes the intersection audit to `enforce: true`.
- W11. The pull request lists, per game, the look in use, the toy, the reshaped verb where there is one, and every default taken for the owner.
- W12. A game below the bar at the end of the wave is not merged; it keeps its folder on its branch and its reserved looks, and the pull request lists it.

### Scope Boundaries

**In scope:** the 35 games, their looks in the ledger and the registry, the README games table, the `game` entry in the lab catalog for `tape-town`.

**Outside this work**

- The five demos rated "No": `feed-the-monster`, `whack-a-mole`, `slingshot-smash`, `animal-tower`, `peg-blaster`.
- Mierennest, which is another session's lane.
- Deploying, which is the owner's act.
- Frame rates on a real iPad; a cloud machine renders in software, and its numbers are reported as such.
- Any change to the lab's demos, and any copy of lab code into `games/`.

### Dependencies / Assumptions

- The brief counted 36 demos. `lab/arcade/catalog.ts` lists 56; 11 have a game under their own key and 5 under a `game:` value (16, not 15); 5 are rated "no". That leaves 35, and the files win.
- `lab/arcade/RATINGS.json` holds no rating for any of the 35, so each design rests on the owner's steer in `lab/arcade/GENTLE.md` and on the pack, not on his having played it.
- The bands are spread on purpose: four games at 2 to 5, three at 3 to 6, six at 3 to 7, two at 4 to 7, eight at 4 to 8, four at 5 to 9, four at 6 to 10, two at 7 to 11 and two at 8 to 12. Each starts from the demo's ages and is moved where the reshaped game asks more or less of the child.
- Six games are three.js (`block-castle`, `sand-kingdom`, `tiny-island`, `box-fort`, `hungry-hole`, `lane-runner`), where the child builds in depth or reads distance; the other 29 are canvas 2D.

### The games

Each paragraph is the brief: the one idea the child feels, the verb in the hand, how the world answers, how a cycle ends and restarts or how open play tidies up, and the day-15 line (pack: game-design, depth-from-combinations.md).

- **Wash Day** (`wash-day`). The child feels mud give way under the finger and makes a dirty friend proud again. Three muddy animals stand at the garden gate in their underwear and hand over one garment each; the finger rubs it on the ridged board (mud lifts where it rubs, suds build), drags across it to wring (water runs out with a squeak), and presses a peg on with a click, and the wind dries it in a few seconds once it hangs. Any garment can be handed to any animal, who puts it on wherever it fits and reacts by its fixed taste (the pig likes things tight, the heron hates wet sleeves), and everything in the yard can be washed, the cat and the pegs included. The cycle ends with the line swaying and three dressed animals walking off, and the next muddy three wait at the gate until touched. On day 15 the child dresses the wrong animal in the wrong thing on purpose, hangs things half wrung to see them drip on who stands below, and knows which animal hates what: garments by tub, board, soap, wringing hands, peg and wearer.
- **Block Castle** (`block-castle`). The child feels a plain block become the tower it was pretending to be. The finger carries blocks from a basket onto the floor, each lands with a knock on whatever is under it and stays, with no toppling; ringing the brass bell draws the evening down and the pile turns, in exactly its own shape, into a lit castle. Six block kinds become six things (a long one a bridge, an arch a gate, a round one a tower with a roof, a thin one a flag pole, a cube a room with a window, a slope a slide), and the small folk use what is there by fixed taste: the king wants the highest seat, the cook the lowest room, the dragon any arch to sleep under, and a castle with no door has everyone climb in through a window. The castle stays as long as the child likes; ringing again brings back the afternoon and the blocks as they lay, and tipping the basket tidies them away. On day 15 the child builds for a result (a slide off the top tower into the moat for the king), since what each folk does comes from which kinds touch which.
- **Hop Across** (`hop-across`). The child feels clever for seeing a gap before it opens. A rabbit with three small ones behind it crosses roads, a river and a railway to a picnic on the far side, one squashy hop per tap, and every other thing moves exactly one of its own steps when the rabbit lands and stands still while the child thinks: a car one square, a lorry two, a log with the current, a turtle that dives on every third step, a train that comes only after its bell is stepped on. A wrong hop is slapstick and free (a pancake that peels itself up, a fish that spits the rabbit back to the bank), and the small ones copy each hop one step late, so they can be led or tangled. The cycle ends with the family at the picnic, and the next crossing lies visible beyond the cloth until the child hops onto it. On day 15 the child uses one mover against another (ride the lorry, wake the train to clear the lane, park the turtle under a small one), because the lanes combine and the rules never change.
- **Flower Table** (`flower-table`). The child feels the snip and then sees a bouquet of their own go out into the world on someone's table, head or goat. A visitor waits at the garden gate holding an empty vase (tall, squat or a boot); the finger crosses a stem to cut it exactly there, the stem drops into the hand, and set in the vase it leans against the others, a stem too long tipping its head and the whole vase if the child insists. Six plants behave differently (the sunflower turns to the window, the thistle pricks whoever sniffs, the dandelion puffs away when breathed on, the ivy climbs out, the poppy drops petals, the onion flower makes eyes water), and each visitor reacts to exactly what was arranged by a taste that never changes: the bee-keeper wants anything with bees on, the bride sneezes at lilies, the goat eats it. The visitor leaves with the vase and the bouquet stays visible in the street behind; the next visitor waits at the gate for a touch. On day 15 the child arranges for an effect: a bouquet of only stalks, or the one mix that makes the stern aunt laugh.
- **Hungry Hole** (`hungry-hole`). The child feels the wobble on the rim and the drop, and then gets it all back as a joke. A hole follows the finger round a carnival street; anything narrower than the hole tilts, slides and falls with a bloop pitched by its size, the hole grows a little with each thing because the child fed it, and things too big teeter on the rim. A tap on the hole makes it burp out what it last ate, and things burped in a row come out stuck together in the order they went in, so a dog, a hat and a tuba come back as a dog wearing a hat playing a tuba, which then walks off down the street as itself. Bystanders have fixed opinions (the mayor chases his hat, the band plays on from inside the hole, muffled), and nobody is hurt. The street never empties by itself and nothing is counted; a burp of everything sends one long parade float out of the gate, and the gate keeper lets the next street in when touched. On day 15 the child swallows in an order chosen for what will come out: five objects by five makes twenty-five pairs before any stack of three.
- **Tiny Island** (`tiny-island`). The child feels a small world wake up wherever a toy is put. A round island sits on a turntable in a flat sea; a tap on a toy in the tray and a tap on the island sets it down with a knock (a drag works too and survives a lifted finger), and a finger on the rim spins the island with a rumble. Each of five toys starts being itself at once and answers its neighbours: the lighthouse sweeps a beam that the cat chases, the boat set on land flaps like a fish and set in the sea sails round the island, the sheep eats whatever tree is nearest, the house puffs smoke that the gull rides. Nothing ends; a tap on the wave at the edge washes the toys back into the tray, and they come out again in the order the child likes. Day 15 looks much like day 1, with the child surer and trying one new neighbour pair (the sheep in the boat), which always gives the same funny answer.
- **Snack Merge** (`snack-merge`). The child feels two soft things pop into a third and learns to cook by collision. A snack with a face hangs from a claw over a glass jar; the finger slides it along the rail and lets go, it drops and squashes, and when it touches a different snack the two merge with a pop into the one thing that pair always makes (bread and cheese a toastie, toastie and chilli a toastie that breathes fire, jelly and anything a wobbling version of it). The child picks the next snack from six on the shelf, so nothing is luck, and a full jar burps its top layer out onto the counter. A large monster sits beside the jar with its mouth at the rim and, when the child tips the jar by its handle, eats what is in it and reacts to exactly that by tastes that never change. The emptied jar stays empty and the next monster looks in at the window until touched. On day 15 the child knows the fifteen pairs and builds third-step snacks on purpose for one monster's worst face.
- **Farm Morning** (`farm-morning`). The child feels that every animal answers, whatever is done to it. Four large animals fill the yard (hens behind a door that slides, a dusty pony, a goat, a pig in mud) and four things lie about (a grain scoop, a pump with a bucket, a brush, a fork of hay); a tap on a thing and a tap on an animal uses it there, and a drag does the same and survives a lifted finger. Sixteen pairs give sixteen different answers with their own sounds: grain patters and the hens come running, water on the pony makes it shake and soak the goat, the brush on the pig tickles it over onto its back, hay on a hen makes a walking haystack. Each animal settles into contentment after its right thing, the morning light is full when all four have theirs, and sliding the henhouse door shut brings the night and a new morning behind the same door, which opens only when touched. Day 15 is day 1 done faster and surer, with one new pair tried on purpose because it was funny yesterday and is funny again.
- **Egg Heist** (`egg-heist`). The child feels the thrill of mischief behind someone's back, with nothing at stake. A goose patrols a farmyard on a fixed round and sees only what is in front of her; the child taps where the raccoon should go, it creeps there, and if her gaze sweeps over it in the open she honks and punts it back to its bush in a high arc, with what it carried left where it fell. Waiting in a bush costs nothing, so the child watches her round and picks the moment. Six things lie about (a ball, a potato, an alarm clock, a boot, a cabbage, the egg) and five places take them (the nest, the pond, the scarecrow, the dog's bowl, the washing line), and every pairing has one outcome that is always the same: the goose sits proudly on the alarm clock until it rings, the dog buries the egg, the scarecrow in a boot hat frightens the goose into the pond. ## Planning Contract

### Key Technical Decisions

- KTD1. **Worktrees from one base commit.** The lead cuts each worktree outside the repo with `git worktree add -b game/<key> <path> <BASE_SHA>`, confirms the head and a clean status, links `node_modules`, and gives the builder a scratch folder and a preview port. At most seven local builders run at once (guide, "Building several games at once"); the 35 games go in batches in the order of the table.
- KTD2. **Two pilots, then the rest.** `wash-day` and `block-castle` are built until each has used every copied helper in a running game. What they had to change goes back into the template and its version is raised before the third game starts.
- KTD3. **The brief is the row and the paragraph.** A builder's brief carries its row, its paragraph, the guide, and the pack; `wave.json` holds the same text for the lead's tooling. The builder writes the sheet from them and invents no other game. Where a paragraph and the pack disagree, the pack wins and the builder says so in its status block.
- KTD4. **No school skill, no records.** A sheet that finds it wants to name a school skill stops and asks the lead; nothing under `education/` is opened for wording.
- KTD5. **The lead keeps the ledger.** The 70 rows are reserved before any builder starts (13 that were open, 57 added). After a merge the game's look becomes claimed and its spare row goes back to open; because the toy checkpoint is not held, spare rows stay reserved until the owner has answered on the look.
- KTD6. **Stills and frame rates are the lead's.** Builders run only their own game's tests and the typecheck. The lead builds, takes one contact sheet of all 35 first frames beside the claimed looks, and measures each game alone on the merged production build.
- KTD7. **A band that starts at 2 is built tap-first.** `tiny-island`, `farm-morning`, `goodnight-teddy` and `rainbow-world` hold targets of about 100 logical pixels, quantities at about five, and no gesture beyond tap and a forgiving drag (pack: game-design, ages-2-to-4.md).

### Sequencing

Reserve the looks and fix the lab catalog entry; pilots; template version; batches of up to seven in table order, each batch through sheet, check of the sheet, toy, game, gates; the lead merges game by game and runs the whole check between batches.

## Definition of Done

- Every merged game opens from the home page, is found as left, and its demo no longer shows as a demo.
- The registry in `docs/art-direction.md` has a row for every merged game, its ledger row is claimed, and the README table lists it.
- The pull request lists for the owner: each game's look and toy as defaults awaiting a yes, each reshaped verb, the games not merged with the reason, and that no frame rate comes from a real iPad.
